# 🧠 ResolveAI Backend

The backend of **ResolveAI**, an AI-powered customer support system that automatically replies to customer complaints via email and tracks their ticket status.

---

## 🚀 Features
- Express.js REST API for managing complaints and replies  
- MongoDB database for ticket storage  
- AI integration (via Hugging Face / OpenAI) for generating automated responses  
- Email sending system using Nodemailer  
- Ticket status tracking and conversation history  

---

## ⚙️ Tech Stack
- **Node.js** + **Express.js**
- **MongoDB / Mongoose**
- **Nodemailer**
- **Axios**
- **dotenv**
