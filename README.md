# 🤖 ResolveAi - Smart AI-Powered Customer Support System

ResolveAi is an intelligent **AI-based customer support portal** that helps businesses handle user complaints, automate email replies, and track support tickets efficiently.  
This project is designed to simplify and enhance the complaint management process using **React (frontend)**, **Node.js + Express (backend)**, and **Axios** for seamless API communication.

---

## 🚀 Features

✅ **Smart Complaint Form**  
Users can easily submit their complaints with their name, email, and issue details. The form stores the complaint on the backend for tracking and further processing.

✅ **AI Email Reply System**  
The system allows AI to generate automatic replies based on user input using integrated AI logic or connected APIs. Users can also send additional messages, and the AI responds accordingly.

✅ **Ticket Tracking System**  
Users can check the current status of their complaint simply by entering their email. The interface shows all message replies in a chat-like format (AI replies in blue, user replies in gray).

✅ **Real-Time Feedback UI**  
Instead of simple browser alerts, the frontend provides smooth user feedback (via modals/toasts), ensuring a more professional user experience.

✅ **Modular Frontend & Backend**  
The project is split into two folders — `/frontend` and `/backend` — allowing independent development and deployment flexibility.

---

## 🏗️ Tech Stack

**Frontend:** React.js, Axios, Vanilla CSS (custom styled for a professional look)  
**Backend:** Node.js, Express.js, MongoDB (or any DB integration ready)  
**Tools Used:** VS Code, Git, GitHub, npm
