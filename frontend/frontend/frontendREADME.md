# 💻 ResolveAI Frontend

Frontend for **ResolveAI** — a smart support portal where users can file complaints, receive AI-generated replies, and check ticket statuses.

---

## 🎨 Features
- Complaint form submission  
- AI-based email reply system  
- Ticket status & chat history view  
- Beautiful UI (custom CSS, no Tailwind)  
- Real-time notifications (no alerts!)

---

## ⚙️ Tech Stack
- **React.js**
- **Axios**
- **CSS**
- **Vite or CRA** (depending on setup)
